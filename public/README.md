# Local media

Place video, image, audio, and font files used by a VideoSpec in this directory. Reference them as `public/filename.ext` in the spec. Confirm that you have the right to use and redistribute each asset.

Locally generated narration is written to `public/generated/`. That directory is
ignored by Git because voices, scripts, and licensing may differ by user. The
VideoSpec remains portable and records the local asset path.
